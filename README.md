# StudentSphere – Student Event Management

StudentSphere is a web-based student event management platform designed to help students discover upcoming events and register easily.

## Features

- 🎓 Student-friendly event website
- 📅 Upcoming event information
- 📝 Event registration form
- 🏆 Technical and cultural events
- 📊 Registration dashboard
- 📱 Responsive design
- 💾 Browser localStorage for registration data

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
